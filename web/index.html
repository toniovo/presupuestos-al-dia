Qué hace con cada consulta

Un flujo simple para no perder datos ni responder con información incompleta.

1. Ordena el pedido

Identifica trabajo, zona, medidas y fecha mencionada.

2. Señala lo que falta

Aplica tus reglas antes de sugerir un precio o una visita.

3. Prepara la respuesta

Prepara un borrador. En el piloto de Gmail podés elegir si se revisa o se envía automáticamente.

Adaptado a cada negocio

Los servicios, la zona y las reglas cambian lo que conviene responder.

Servicios y zonaDefiní qué trabajos hacés y dónde atendés.
Preguntas necesariasFotos y alcance para una reforma; modelo y ubicación para una instalación.
Tono y límitesElegí cómo hablar y qué precios o plazos nunca afirmar sin confirmar.

Vos decidís si se envían correos

En el piloto de Gmail, una casilla permite activar o desactivar el envío automático. Empieza apagada. Solo se procesan las conversaciones que el negocio etiqueta; los casos delicados quedan para revisión. La prueba de esta página no envía correos.
